<h3 align="center">✨ Key Features</h3>

<p align="center">
  📄 Resume Analysis & Document Import<br/>
  🎯 Job Description Parsing & Job Matching<br/>
  ✍️ AI-Powered Resume Tailoring<br/>
  📝 Cover Letter Generation<br/>
  🎤 Interview Coaching<br/>
  🤖 Multiple LLM Provider Integration<br/>
  🔑 Bring Your Own Key (BYOK) Support<br/>
  🔐 JWT Authentication & Secure Password Hashing<br/>
  📂 PDF & DOCX Document Extraction<br/>
  🧪 Automated Backend & Frontend Testing
</p>

<h3 align="center">⚙️ Technology Stack</h3>

<p align="center">
  <code>Python</code> <code>FastAPI</code> <code>React</code>
  <code>TypeScript</code> <code>SQLite</code>
  <code>Gemini API</code> <code>Groq API</code>
  <code>Pytest</code> <code>Vitest</code>
</p>

<h3 align="center">💡 Engineering Highlights</h3>

- Developed modular REST APIs using FastAPI and Pydantic.
- Integrated Gemini and Groq-compatible LLM providers with structured output validation.
- Implemented timeout handling and automatic provider fallback.
- Built secure user authentication using JWT and Argon2id.
- Developed reusable React components with typed API contracts.
- Added automated tests and continuous integration using GitHub Actions.
- Deployed frontend on Vercel and backend on Render.
